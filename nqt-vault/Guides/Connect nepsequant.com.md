# Connect nepsequant.com

1. nepsequant.com → Settings → AI agents → create key (tick Paper trading)
2. `./nqt-connect login` then `./nqt-connect status`
3. Start [[TUI Dashboard]]

Details: [[Website Connect]]. Opt out of shared book: `NQT_SHARED_BOOK=0`.
