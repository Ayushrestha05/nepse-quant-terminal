# Project Overview

NEPSE Quant is a research and paper-trading application for Nepal Stock Exchange data. The repository README contains the detailed setup and product overview: [Open README](../README.md).

The desktop client uses local SQLite market data, paper-account ledgers, and offline research tools. See [[architecture/PROJECT_STRUCTURE|Project structure]] and [[EASY_LAUNCH|Easy Launch]].

The rationale and verification for implementation changes are recorded in [[project-vault/Home|the change log]].
