# TUI Dashboard

`apps/tui/dashboard_tui.py` + `dashboard_tui.tcss`. State via mixins under `apps/tui/state/mixins/` (lifecycle, tab refresh, agent chat, trading engine, website strategies, …).

Shortcuts: `1`–`0` tabs, `L` lookup, `A` analyse, `R` refresh, `/` palette, `Q` quit. Full list in root README.
