# Website Connect

- CLI: `apps/cli/connect.py` → `./nqt-connect login|status|paper|real|logout`
- TUI IO: `apps/tui/io/website_book.py`, `website_lookup.py`, `website_strategies.py`, `website_floor.py`
- Keys: `~/.config/nepse-quant-terminal/credentials.json` (HTTPS to nepsequant.com only)

Enables shared paper book, website lookup pages, floorsheet broker panels, website strategies + auto-trade.

Guide: [[Connect nepsequant.com]]. Consumers: [[TUI Dashboard]], [[Paper Trading]], [[Tab Lookup]], [[Tab Strategies]].
